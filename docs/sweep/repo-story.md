No effect on the public scrub or upstream QEMU merges.
**(ii) Move non-emulator code out of qemu-ios** (imgtools, manifests, guest helpers `contrib/it-*`/`ipad1-*`/appsync/guest-package, `tests/ipad1` + the device-pipeline tests, docs) into LTM. Costs: an 11k-commit QEMU lineage plus upstream merges become subtree pulls; the scrubbed public `ipad1` becomes subtree-split + filter-repo per refresh; usbmuxd (LGPL) inside a private app tree complicates the public story; every agent worktree carries the QEMU tree (39 build dirs today already).
