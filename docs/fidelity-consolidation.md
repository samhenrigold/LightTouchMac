## Changes

- Swift FirmwareKit owns creation for all three boards. The CLI accepts
  `--catalog --id` and reads the app's catalog; Python device commands only
  translate inputs and delegate. Old orchestrators and board builders are deleted.
  Only the N45 bake and N72 GL-bake reference functions remain in the frozen archive;
  separate Python binary-format tools remain useful for research and format tests.
  `tests/fresh-device.sh` calls Swift directly and requires every selected check.
- The decrypt cache uses format 2, tool/version/board/product/IPSW/key identity,
  immutable paths, advisory locks, unique staging, and SHA-256/size manifests.
  Corruption including a same-size edit causes a rebuild. Failed production
  leaves the previous entry available. Eight simultaneous producers publish once.
- Corpus tests require explicit `FK_TEST_CORPUS=1` or `FK_REQUIRE_FIXTURES=1`.
  Missing selected prerequisites fail, rather than returning success or filtering
  out the case. Synthetic NAND and preference contracts run without corpus inputs.
  The app and emulator runners support `--require-inputs`; empty selections fail.
- Independent legacy hashes replace live Python builders for N72 NOR, all 50 NAND
  metadata pages, and K48 iBoot/NOR/GID artifacts. They were captured from the
  independent `0be1499f24` implementations, then compared against Swift. They are
  not regenerated by the implementation being tested.
- iPad kernel, iBoot and SecureROM boot strategies are typed and validate their
  required images/NOR/keys. Unknown strategies fail. Legacy nil strategy means
  kernel; incidental keys no longer choose the boot path.
- FMSS transfers NAND pages and reports a pre-read notification; firmware policy
  and its state are owned by the iPod board. The iBoot Bluetooth string rewrite
  is removed after the six-device regressions. A remaining boot-argument
  compatibility write is described below.
- PMGR watchdog countdown advances on virtual time and schedules resets without
  waiting for another MMIO write. Feed, disable/re-enable and compare changes
  reschedule it; migration v2 retains the deadline and reads v1 state. Timer
  resources are freed on finalization.
- USB readiness uses live queries against the intended UDID and bridge. Persistence
  checks require successful AFC write, immediate readback, guest-confirmed halt,
  and identical data after reboot. iPad charging restarts use the existing PMU
  confirmation latch through a read-only QOM property. Lost agent replies are
  observed, never retried. OCR compilation now publishes an atomic cached binary
  and works on a clean worktree.
- Native session tests accept an explicitly supplied signing requirement for a
  supplied test helper. The project-team requirement remains the default;
  production authentication is unchanged. This lets developers use an exact
  ad-hoc helper code hash without disabling authentication.

## ANGLE decision

A pinned Metal-only release ANGLE build passes native ES1 fixed-function and ES2
original-GLSL triangle/readback/context-switch probes. The compiled renderer imports
198 GL API names; ANGLE directly exports 152, with 46 requiring renames, adapters
or replacements. Most of the 7,801-line executor plus 1,225-line snapshot code
owns guest transport, memory, surfaces and object identity and would remain.

Keep CGL as production for this consolidation. The native probes establish API
viability, not guest robustness or reduced total complexity. ANGLE backend adoption
still needs API-version transport, surface/format adapters, snapshot support and
guest corpus acceptance. The pinned build, probes, inventory and measured decision
are in qemu-ios `docs/research/angle-evaluation.md`; no experimental backend is
silently substituted in the app.

## Fidelity limits

- The iPod SecureROM path still has a board compatibility command-line write.
  A no-injection 5F138 experiment with generated NOR `boot-args` produced a blank
  `gBootArgs.commandLine` and kernel command line. It does not justify deleting
  that workaround or claiming native NVRAM delivery. The experiment is isolated
  in `/private/tmp/qemu-ios-fidelity-nvram` and its artifacts in
  `/private/tmp/fidelity-nvram-stock-probe`.
- 2.1.1 reaches Connect to iTunes in the existing fixture; that is the known
  activation baseline, not a passing home-screen acceptance case in this matrix.
- The watchdog's 24 MHz rate follows the existing PMGR timebase model; independent
  silicon measurement is still needed. PLL/gate polling contracts are tested;
  complete peripheral frequency/gating effects are not modeled.
- Restore is not yet the preparation pipeline and a restored stock UI is not
  verified. Injected GL support and other declared guest stand-ins remain necessary.
- The development dylib links host Homebrew libraries. Its successful local build
  does not certify the release's macOS 14.4 dependency compatibility or signing.
