# Smoke: anomalies worked around or unexplained

Sam, 2026-09-28: "I really hope they are treating them as 'this is broken because our emulator has a gap' and not just
'a hurdle to hack around at skin-deep level'. Where there's smoke, there's fire."

Every workaround, instrument, or unexplained anomaly goes here with its fidelity class (see fidelity-ledger.md) and the
fire we suspect behind it. An entry leaves this list only when the cause is modelled faithfully or shown to be
real-hardware behaviour. New entries are added by whoever ships a workaround; none is closed by deleting it.

Closed:
- iPod 2.x Hold "did nothing" and hold-and-slide never confirmed (#19): the hold button was fine (the 2.x DeviceTree has `function-button_hold` <gpio 0x0c02> like 3.x; Hold locks the screen). The machine's gesture held Home through the settle and pressed Hold in the same tick as the release (both edges in one GPIO status read, 0x06000000; no power-off sheet on an unlocked 2.x home screen); Home is now a tap. Then 2.x's AppleD1759PMU-36.2 halt, tethered, waits in software for the cable to come out ("pmu waiting for stdby"; EVENT_A bit 3 -> 0x0a bit 0) where 3.x/4.x's -94.7 writes 0x6f=0x90: real-hardware behaviour, already modelled by the PMU (R); the gesture (S, host input) now unplugs once the guest has darkened the backlight rail. qemu-ios `ipod-2x-hold` 19649e467c. 2026-09-29.
- iPod 4.0 betas' clean shutdown ~30 s (8A248c, 8A260b) or never (8A230m): at the agent halt the I2S driver (AppleS5L8900XI2SController) powers the block off (TXCOM = 0, RXCOM = 0, reg 0 = 0x30) and spins on reg 0 bit 1 with no timeout; the model echoed reg 0, so the bit never set (14M reads in 40 s; the spin holds the CPU, on 8A230m itunesstored's exit and launchd's kill() behind it never finish). 8A274b onward write 0x20 and skip the wait behind a flag; the poll is still in the release driver. Bit 1 now reads "stopped" while bit 0 is clear (R, qemu-ios `smoke-4` 436eaadc1a). Agent halt to PMU power-off: 8A230m >600 s -> 1.3 s / 0.9 s, 8A260b 29.2 / 23.4 s -> 1.4 / 0.7 s, 8A293 unchanged. 2026-09-29.
- iPad seal boot hung at FPart Init after the iop-core merge: iBoot's read-modify-write of FMI control bit 7 was counted as a second page transfer; a FIFO flush had hidden the phantom pages for months; transfer rule now matches iBoot and EmbeddedIOP; drain no longer re-queues (R). 2026-09-29.
- iPod 4.2.1 "No Wi-Fi": card reported chip number 0 → real chip id word (R). 2026-09-28.
- iPod 4.2.1 screen only dims: PMU regulator-enable bit now honoured (R). 2026-09-28.
- iPad 4.3 DSI assert at display-off: StopStateClk semantics corrected (R). 2026-09-28.
- iPad 4.3.5 "epoch roll wait": NAND signature epoch read off the kernel (pipeline, generic). 2026-09-28.
- iPod 3.0 never printed: direct-iboot epoch hard-coded → found by pattern per iBoot (R). 2026-09-28.
