Light Touch Help

Using the device
Click and drag on the screen as you would with a finger. Pinch on a trackpad, or Option-drag on the screen, to use two fingers. Home is ⇧⌘H; Lock is ⌘L. The Lock toolbar menu also has Power Off. Powering off leaves Light Touch open; choose Power On to start the device again.

Rotate with ⌘← or ⌘→. These shortcuts leave text fields alone while you edit. View contains Actual Size, Zoom to Fit, and zoom controls. Settings (⌘,) controls automatic rotation.

Keyboard access
Turn off Device → Send Keyboard Input to Device, then choose View → Focus Device Screen. Arrow keys move a visible pointer. Hold Space to touch and use arrows to drag; release Space to lift the finger. Shift-arrow also drags until you release the arrow keys or Shift. The pointer stops interacting when the device sleeps or loses focus. Turn keyboard input back on to type into guest apps. Mac Command and Control shortcuts, including VoiceOver, stay with macOS.

Motion and controllers
Drag beside the device to roll it. Two-finger scrolling beside it controls roll and pitch. Hold Option and use the arrow keys to tilt; Option–Space shakes. The Motion toolbar menu selects Upright or Flat and keyboard tilt speed. The small horizon appears while tilted; click it to level the device.

A connected game controller uses the left stick for tilt, A to hold a screen point, Menu for Home, and Options to shake. Settings selects the stick response and A-button point, expressed as percentages from the screen’s top-left corner. Input works while the device screen has keyboard focus and the device is awake. Controller release, disconnection, and switching to mouse input release its touch.

Apps and media
Use Apps → Install App to choose a decrypted, compatible IPA, or search the Legacy Store. You can also drag apps onto the device. Imports and installations share the inspector’s queue.

Apps → Sync Media accepts MP3, M4A, AAC, WAV, JPEG, PNG, and HEIC files. Songs appear in Music; images appear in Saved Photos. Raw AAC is converted by macOS before upload. New song imports recognize identical content on repeat imports. Songs imported by older builds are not automatically indexed for duplicate detection. Keep virtual USB connected while transferring. If an import reports an uncertain result, check the device library before importing it again.

Capturing the screen
The Capture menu and customizable toolbar offer Save Screenshot, Copy Screen (⇧⌘C), Live Text (⇧⌘L), and recording (⇧⌘R). Live Text selects text directly over the device screen; click its button again or press Escape to dismiss it.

Recordings include device audio and use a 480 × 480 canvas that preserves native pixels through rotation. Stop Recording opens the save sheet. Pausing the emulator leaves a silent interval in the recording. Finger dots are optional; they do not respond while the device is asleep or off.

Browsing the web
Device → Proxy selects no proxy, the built-in HTTP proxy, or a dated Internet Archive replay. Nothing separate needs installing. Archived pages depend on available captures and archive rate limits. A modern site’s scripts or layout may still exceed this old version of Safari.

With the HTTP proxy enabled, Weather uses Open-Meteo forecasts and city search (https://open-meteo.com/, CC BY 4.0). The free service is for noncommercial use. If an old saved city no longer updates, remove it and add it again. The moon icon shows an approximate phase.

Battery and device state
The inspector shows device, proxy, and guest-agent status above the app list. Click its battery row, or choose Device → Battery, to open the battery popover. It controls target capacity, charging, drain per emulated minute, and virtual USB. The guest filters battery readings, so its displayed percentage can lag a changed target. Pausing stops drain. Automatic charging while USB is connected also stops drain.

Device → Pause freezes the emulator; Resume continues it. Save State Now is available for supported machine states. Live accelerated graphics contexts cannot yet be saved, and Light Touch reports that limitation. Discard Saved State removes saved memory state without erasing the device’s stored apps and data.

Recovery and diagnostics
Device → Advanced contains Restart SpringBoard, Open SSH, Verbose Boot, and Kernel Console. Boot options apply on the next boot. File → Export Diagnostics collects information useful for reporting a problem. Prefer normal Power Off or Quit so the guest can finish writing its filesystem.

Restart and Erase All Content and Settings require confirmation. Erase removes the device’s installed apps, media, and settings. It is not a routine repair step.

Device logs

File → Device Logs shows the latest boot/kernel console and USB logs, including the previous rotated files. Updates pause while text is selected or Pause updates is checked. Use Find to search the displayed tail, or File → Export Diagnostics for the complete retained logs. Kernel messages require Kernel Console to be enabled.

Device status and logs

A status message above the device explains preparation, saved-state, erase,
or shutdown failures. Choose Show Logs for details, or Dismiss after reading.
Successful retries clear the matching message. Storage-write failures keep
the message visible until you free disk space and reopen Light Touch.
File > Device Logs includes app events, the device console, and USB service
logs. Text is selectable; use Find to search. Export Diagnostics includes
these logs so you can attach them to a bug report.

DEVICE FILES
Choose View → Files to browse the device’s Media folder in columns. Import copies a file into the selected folder; an existing file with different contents is preserved. Export saves a selected file to your Mac. Transfers show byte-based progress and can be cancelled. Choose Device to return to the screen. Files is also available when customizing the toolbar.
